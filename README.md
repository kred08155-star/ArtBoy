# Animate Lab

A lightweight Adobe Animate-inspired motion design prototype built as a single-page web app.

## Features

- Timeline-based animation workflow
- Add rectangles, circles, and text objects
- Drag objects directly on the stage
- Create keyframes from the current frame
- Play the animation preview
- Inspect and tweak x/y/width/height/rotation/fill values

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

This is intentionally a focused prototype inspired by Adobe Animate's feel and workflow, not a full production replacement for the tool.

The app is fully client-side and requires no build step.
